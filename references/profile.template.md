## Tracker sheet

- **Spreadsheet URL:** [Only fill in if the candidate created their own tracker in the wizard. Leave
  as "not configured" otherwise — scheduled sync mode requires this.]
- **Columns (A→I):** `Company | Position | Location | Match | Status | Applied | Cover Letter | Source Link | Notes`
- **Identity key:** a row is uniquely `Company` + `Position` (case-insensitive). Never create a
  second row for a pair that already exists — update it instead.
- **Status vocabulary:** `Interviewing`, `Applied`, `Applied (referral)`, `Rejected`, `To apply`,
  `To review`, `Hold`. Real applications outrank leads: if an inbox confirmation shows an application
  was submitted for something that was only a lead in the sheet, promote its row (set
  `Status=Applied`, fill `Applied` date) rather than adding a new row.
- **Dates:** ISO `YYYY-MM-DD`.
- **Row color coding** (fill the whole row):
  - **Yellow** — positions newly added in today's run (leads or applications first seen today).
  - **Green** — in process: Status `Interviewing`, `Applied`, or `Applied (referral)`.
  - **Gray** — Status `Rejected` or `Not relevant`.
  - **No fill** — everything else (untouched leads: `To apply`, `To review`, `Hold`).
  - Recolor on status change: e.g. a green `Applied` row that gets rejected becomes gray; yellow is
    only for the current day and reverts to its status color (green/none) on the next run.
